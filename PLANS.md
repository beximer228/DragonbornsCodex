# Cheat Menu — планы

Добавлено 2026-10-24. Порядок внутри разделов — от самого полезного.
Перед каждой новой функцией: найти готовые моды с похожей логикой, разобрать их, потом писать своё.

## Самое ценное

- [ ] **Автосохранение перед необратимыми действиями.** Кнопки «навсегда» (Тан во всех владениях, Стать вампиром, Брак, Развод, Знать все зачарования и т. д.) перед выполнением делают сейв с именем вроде `Before_ThaneAll`, после подтверждения.
- [ ] **Поиск по всем настройкам на обоих языках.** Поиск по меню уже есть (Ctrl+F, ищет по текущему языку и показывает найденные строки). Осталось: искать сразу по EN и RU и по клику переносить к нужному переключателю на его странице.
- [ ] **Активные эффекты на Довакине.** Список всех магических эффектов (болезни, баффы, дебаффы, эффекты модов) с кнопкой «Снять» у каждого. Там же кнопка «Вылечить все болезни»: иммунитет есть, а лечения уже подхваченных нет.
- [ ] **Пресеты читов.** Сохранение и загрузка набора включённых опций и значений слайдеров («лёгкая игра», «скриншоты», «тест билда»), экспорт и импорт в файл.
- [ ] **Телепорт к цели квеста.** В разделе «Квесты»: переместиться к маркеру текущей задачи.

## Цель / NPC

- [ ] Редактор цели: уровень, здоровье, урон, рост, уровень отношений, агрессия, уверенность.
- [ ] Сменить одежду цели или раздеть её; выдать предмет цели.
- [ ] Сделать цель торговцем или тренером.
- [ ] «Мир для всех»: животные и существа не нападают (как Animal Allegiance).

## Спутники и лошадь

- [ ] Несколько спутников одновременно и их лимит.
- [ ] Инвентарь и экипировка спутника из меню; уровень спутника равен уровню игрока.
- [ ] Лошадь: призвать к себе, скорость, бесконечный запас сил.

## Бой

- [ ] Без оглушения (stagger) и без ragdoll от «Безжалостной силы».
- [ ] Шанс крита, множитель скрытой атаки.
- [ ] Сила криков, ×.
- [ ] Снятие капа брони (сейчас 80 %).
- [ ] Спавн врагов по уровню для тренировки и кнопка «Убрать заспавненных».

## Предметы и магия

- [ ] Редактор предмета: урон, броня, вес, стоимость, имя одного конкретного предмета.
- [ ] Конструктор заклинаний и зелий по аналогии с зачарователем: свой спелл или зелье из любых эффектов.
- [ ] Дублировать предмет; массово продать или удалить по фильтру.

## Мир

- [ ] Режим выживания: заморозить голод, холод и усталость.
- [ ] Купить все дома и сразу обставить их.
- [ ] Телепорт к точке под прицелом (blink).
- [ ] Отметить локацию зачищенной.

## Фото-режим

- [ ] Один раздел: FOV, заморозка NPC в позе, скрытие игрока, остановка времени, свободная камера. Часть уже есть отдельно (Свободная камера / tfc, Скрыть интерфейс, Остановить время), осталось собрать вместе и добавить недостающее.

Второй список идей (добавлено 2026-10-24). По популярности отдельных модов самые востребованные: достижения с модами, цифры урона и оверлей активных читов.

## Интерфейс и оверлеи

- [ ] **Мини-оверлей активных читов** при закрытом меню: плашка в углу экрана с тем, что включено (Режим бога, полёт, аимбот).
- [ ] **Всплывающие цифры урона** над врагами; отдельные цвета для крита и для урона магией.
- [ ] Координаты и текущая ячейка (локация, FormID ячейки) — для телепорта и отладки.
- [ ] Отмена последнего действия для обратимых переключателей и кнопок.
- [ ] Проверка конфликтов горячих клавиш, в том числе с клавишами самой игры.

## Информация

- [ ] Скрытые характеристики игрока: реальная броня, все сопротивления, шанс крита, множители навыков, бонусы от зачарований.
- [ ] Инфо о цели: FormID, мод-источник, уровень, фракции, отношение к игроку, класс.
- [ ] Инфо о предмете в списке выдачи: мод-источник, эффекты, кто им пользуется.

## Характеристики

- [ ] Слайдеры сопротивлений: огонь, мороз, электричество, яд, магия, болезни.
- [ ] Множитель опыта персонажа отдельно от прокачки навыков.

## Оборотень и вампир

- [ ] Стадия вампиризма 1–4 вручную; отключение урона от солнца.
- [ ] Ветки способностей оборотня и Лорда-вампира: выдать или сбросить.
- [ ] Бесконечная Звериная форма (по длительности; «Силы без перезарядки» уже снимают раз-в-день), мгновенное питание.

## Добыча и крафт

- [ ] Множитель лута: золото в контейнерах, ингредиенты со сбора.
- [ ] Количество за крафт ×N (зелья, стрелы, слитки).
- [ ] Улучшение выше «Легендарного».
- [ ] Автоловля душ: душа попадает в камень без заклинания «Ловушка душ».
- [ ] 100 % возврат стрел из тел.

## Мир (дополнительно)

- [ ] Отключить случайные встречи (засады, курьеры, талморские патрули).
- [ ] Убрать трупы вокруг — для производительности в долгих сессиях.
- [ ] Гравитация Havok: низкая гравитация, сила броска предметов.
- [ ] Езда на лошади в городах.
- [ ] Оседлать любого дракона без «Подчинения воли».
